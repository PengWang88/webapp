Frontend Design Styles

前端设计风格图鉴

把同样的卡片、按钮、输入框放进 11 种视觉语言里，你会立刻看清每种风格的核心差异——不是颜色不同，而是「光」与「秩序」的处理方式不同。

01

新拟态Neumorphism

所有元素与背景同色，仅靠一组「左上亮、右下暗」的双向阴影，让 UI 看起来像是从背景中被挤出或凹陷进去。它追求柔和、有触感的数字质感，但对比度低，无障碍上需要额外注意。

  • 同色阴影
  • 双光源
  • 低对比
  • 大圆角
  • 内阴影 = 凹陷

Player

柔和的光，来自左上角

核心手法

用两个方向相反的 box-shadow，亮色投向暗侧、暗色投向亮侧。凹陷状态则换成 inset，模拟被按下去的效果。

适用场景

智能家居面板、音乐播放器、计算器等需要「实体感」的轻量界面。不适合信息密集或需要强可读性的产品。

box-shadow: 12px 12px 28px #b9c1cc, -12px -12px 28px #ffffff;
02

玻璃拟态Glassmorphism

半透明的磨砂玻璃面板漂浮在彩色背景之上，靠 backdrop-filter 模糊下方内容，再用一道细微的亮边勾出玻璃厚度。背景越丰富，玻璃质感越明显。

  • 背景模糊
  • 半透明填充
  • 亮边高光
  • 彩色光斑
  • 层次感

核心手法

backdrop-filter: blur() 配合 rgba 背景与 1px 半透明边框。背后必须有内容可模糊，否则玻璃感会消失。

适用场景

数据仪表盘、媒体播放器、iOS / macOS 风格的浮层。要注意性能与文字对比度。

backdrop-filter: blur(18px) saturate(170%); background: rgba(255,255,255,.14);
03

新粗野主义Neubrutalism

粗黑描边、纯色色块、无模糊的硬边阴影、故意「不精致」的排版。它拒绝渐变与柔和过渡，用高对比和原始感制造视觉冲击，同时保持极高的可读性。

  • 粗黑描边
  • 硬阴影
  • 纯色块
  • 无圆角
  • 高对比

核心手法

border: 4px solid #000 加 box-shadow: 8px 8px 0 #000（零模糊）。按下时位移 4px 并收回阴影，形成物理按压感。

border: 4px solid #000; box-shadow: 8px 8px 0 #000;
04

拟物化Skeuomorphism

模仿真实世界的材质与物理结构——皮革缝线、金属拉丝、塑料按钮的高光与内陷。目标是让用户凭直觉就知道「这个可以按下去」。

  • 材质模拟
  • 渐变高光
  • 内阴影凹陷
  • 立体按钮
  • 纹理

核心手法

用多层 linear-gradient 模拟材质反光，配合 inset 阴影做凹陷、外阴影做悬浮，再叠加细微纹理增强真实感。

适用场景

需要强直觉操作的场景，或刻意的复古风格设计。在扁平等宽屏语境下使用会显得过时，需谨慎。

box-shadow: inset 0 2px 6px rgba(0,0,0,.14), inset 0 -1px 0 #fff;
05

扁平化Flat Design

去掉一切立体效果——没有阴影、渐变和高光，只用纯色块、清晰的字形和简明的图标。信息本身成为唯一主角，也让界面在任何分辨率下都清晰锐利。

  • 零阴影
  • 纯色块
  • 几何图标
  • 清晰层级
  • 轻量加载

核心手法

统一使用纯色背景与无阴影的卡片，靠颜色对比和间距建立层级；图标尽量用单一几何形状。

适用场景

后台管理系统、企业级产品、需要高可读性和跨设备一致性的界面。缺点是容易缺乏辨识度。

box-shadow: none; background: #2d6cdf; border-radius: 6px;
06

极简主义Minimalism

用最少的元素、最大的留白和克制的色彩，让内容本身成为主角。每一条分割线、每一个间距都经过计算——少不是目的，准才是。

  • 大量留白
  • 细线条
  • 克制的色彩
  • 字体层级
  • 呼吸感

07

赛博朋克Cyberpunk

高饱和霓虹色在纯黑背景上发光，配以等宽字体、扫描线与故障感。它表达的是技术失控的未来夜景——信息过载，但每一处都在发光。

  • 霓虹发光
  • 纯黑背景
  • 等宽字体
  • 扫描线
  • 故障感

08

瑞士国际主义Swiss Style

严格的网格、无衬线字体、左对齐、大量留白与一抹红色点缀。信息层级被压缩到最清晰的状态——「无个性」反而成为最强大的个性。

  • 网格系统
  • 无衬线字体
  • 左对齐
  • 红黑配色
  • 严格层级
Typography / 1957

Grid
System.

Helvetica 诞生于 1957 年，它让「中性」成为一种设计主张。

  • 01 — 网格
  • 02 — 对齐
  • 03 — 留白

核心手法

用 CSS Grid 建立严格的列系统，字号跨度拉开（10px → 54px），颜色只用黑、白、红三色。

适用场景

编辑类产品、企业官网、数据密集型页面。是最耐用、最不容易过时的一种排版语言。

display: grid; grid-template-columns: 1.1fr .9fr; letter-spacing: -.045em;
09

黏土拟态Claymorphism

像橡皮泥捏出来的 3D 质感——超大的圆角、厚重的内外双层阴影，配合马卡龙色系，让界面显得蓬松、可爱、有体积感。

  • 超大圆角
  • 内外双层阴影
  • 马卡龙色
  • 蓬松体积感
  • 柔和光
◕‿◕

Clay Card

软软糯糯的体积感

核心手法

三层阴影叠加：顶部 inset 白色高光、底部 inset 深色阴影、外部投影。圆角通常大于元素高度的 20%。

适用场景

儿童教育、社交应用、消费级 App 的引导页。甜度高，不适合严肃或专业场景。

box-shadow: inset 0 -12px 24px rgba(120,100,200,.35), inset 0 12px 24px rgba(255,255,255,.65), 0 24px 46px -14px rgba(110,90,190,.55);
10

蒸汽波Vaporwave

粉色与青色渐变的落日、透视网格、日文字符与希腊雕塑——80 年代消费主义与早期数字美学的怀旧拼贴。它不追求实用，只追求氛围。

  • 粉青撞色
  • 透视网格
  • 霓虹描边
  • 日文字符
  • 怀旧拼贴

a e s t h e t i c

核心手法

两层 linear-gradient 画出网格，再用 transform: perspective() rotateX() 压成透视；标题用多重 text-shadow 做错位重影。

适用场景

音乐专辑页、活动海报、个人主页。属于强表现力的氛围型风格，适合做视觉焦点。

transform: perspective(300px) rotateX(62deg); text-shadow: 3px 3px 0 #ff71ce;
11

包豪斯Bauhaus

以圆形、方形、三角形三种基本几何体构建画面，搭配红黄蓝三原色与粗重字体。把「形式追随功能」推到极致——装饰即结构。

  • 几何基本形
  • 三原色
  • 粗黑字体
  • 非对称构图
  • 功能主义

核心手法

只用 border-radius: 50%、正方形和 CSS 三角形三种形状，配色锁定 #d93b2b / #1b3a93 / #f2c200。

文化机构、展览海报、设计工作室官网。几何语言天生适合做品牌识别系统。
